# 5분봉 캔들 한글 코드 사양서

## 개요

5분봉 캔들을 **한글 한 글자**로 표현하고, 연속된 두 캔들의 관계를 **또 다른 한 글자**로 표현하는 시스템.

---

## 1. 기본 정의 (공통 변수)

| 이름 | 기호 / 식 | 설명 |
|------|-----------|------|
| 시가 | `O` | Open |
| 고가 | `H` | High |
| 저가 | `L` | Low |
| 종가 | `C` | Close |
| 전체 범위 | `range = H - L` | 캔들의 high–low 전체 폭 |
| 몸통 길이 | `body = |C - O|` | 양/음 관계없이 절대값 |
| 윗꼬리 길이 | `U = H - max(O, C)` | 고가에서 몸통 윗변까지 |
| 아랫꼬리 길이 | `Lw = min(O, C) - L` | 몸통 아랫변에서 저가까지 |
| 몸통 비율 | `body_pct = (range > 0 이면 body / range × 100, 아니면 0)` | 전체 범위 중 몸통이 차지하는 비율(%) |
| 윗꼬리 비율 | `U_pct = (range > 0 이면 U / range × 100, 아니면 0)` | 전체 범위 중 윗꼬리 비율(%) |
| 아랫꼬리 비율 | `Lw_pct = (range > 0 이면 Lw / range × 100, 아니면 0)` | 전체 범위 중 아랫꼬리 비율(%) |
| 상대 변동성 | `range_rel = (range_ma > 0 이면 range / range_ma × 100, 아니면 100)` | 최근 N개(예: 60개) 5분봉의 평균 range 대비 현재 range 비율(%) |
| 꼬리 유사도 비율 | `shadow_sim_ratio = (max(U, Lw) > 0 이면 |U - Lw| / max(U, Lw) × 100, 아니면 0)` | 두 꼬리 길이의 상대 차이(%) |

---

## 2. 단일 캔들 표현 (V-D-S → 한글 한 글자)

**초성(변동성) + 중성(방향성) + 종성(꼬리) = 한글 한 글자**

### 2-1. 변동성 (V) → 초성 (4단계)

| 코드 | 조건 | 초성 | 의미 |
|------|------|------|------|
| V1 | `range_rel < 50%` | **ㅇ** | 극소 변동성 (평소의 절반 이하) |
| V2 | `50% ≤ range_rel < 150%` | **ㄴ** | 보통 변동성 (평균 수준) |
| V3 | `150% ≤ range_rel < 250%` | **ㄷ** | 확대 변동성 (평소보다 큼) |
| V4 | `range_rel ≥ 250%` | **ㄹ** | 폭발 변동성 (매우 이례적) |

- `range_rel = range / range_ma × 100`
- `range_ma`: 최근 N개(예: 60개) 5분봉 `range` 평균

### 2-2. 방향성 (D) → 중성 (7단계)

| 코드 | 조건 | 중성 | 의미 |
|------|------|------|------|
| D0 | `body_pct ≤ 2%` 또는 `body/O ≤ 0.5%` | **ㅡ** | 도지 (방향 없음) |
| D1 | `C > O` 그리고 `2% < body_pct ≤ 40%` | **ㅏ** | 약한 양봉 |
| D2 | `C > O` 그리고 `40% < body_pct ≤ 70%` | **ㅑ** | 중간 양봉 |
| D3 | `C > O` 그리고 `70% < body_pct` | **ㅗ** | 강한 양봉 |
| D4 | `C < O` 그리고 `2% < body_pct ≤ 40%` | **ㅓ** | 약한 음봉 |
| D5 | `C < O` 그리고 `40% < body_pct ≤ 70%` | **ㅕ** | 중간 음봉 |
| D6 | `C < O` 그리고 `70% < body_pct` | **ㅜ** | 강한 음봉 |

### 2-3. 꼬리 구조 (S) → 종성 (4단계)

| 코드 | 조건 | 종성 | 의미 |
|------|------|------|------|
| S0 | `U_pct ≤ 5%` 그리고 `Lw_pct ≤ 5%` | **ㅁ** | 꼬리 거의 없음 (마루보즈) |
| S1 | `max(U_pct, Lw_pct) > 5%` 그리고 `shadow_sim_ratio ≤ 20%` | **ㅂ** | 양쪽 꼬리 비슷 |
| S2 | `U_pct > Lw_pct` 그리고 `shadow_sim_ratio > 20%` | **ㅅ** | 윗꼬리 우세 |
| S3 | `Lw_pct > U_pct` 그리고 `shadow_sim_ratio > 20%` | **ㅈ** | 아랫꼬리 우세 |

- `shadow_sim_ratio = |U - Lw| / max(U, Lw) × 100`

### 2-4. 한글 캔들 코드 예시

| 패턴 | V-D-S | 초성+중성+종성 | 결과 |
|------|-------|----------------|------|
| 점상한가 | V4-D3-S0 | ㄹ+ㅗ+ㅁ | **롬** |
| 점하한가 | V4-D6-S0 | ㄹ+ㅜ+ㅁ | **룸** |
| 해머형 | V2-D1-S3 | ㄴ+ㅏ+ㅈ | **낮** |
| 슈팅스타형 | V3-D5-S2 | ㄷ+ㅕ+ㅅ | **덧** |
| 롱레그드 도지 | V4-D0-S1 | ㄹ+ㅡ+ㅂ | **릅** |

## 3. 두 캔들 관계 표현 (PB-Q-PR → 한글 한 글자)

**초성(몸통 위치) + 중성(거래량) + 종성(레인지 위치) = 한글 한 글자**

### 3-1. 상대 위치 6가지 공통 정의

앞 구간 `[A_low, A_high]`, 뒤 구간 `[B_low, B_high]`  
(몸통이면 O/C의 min·max, 레인지면 L/H)

| 코드 | 유형 | 조건식 |
|------|------|--------|
| P0 | 뒤가 앞 안에 완전 포함 | `A_low ≤ B_low AND B_high ≤ A_high` |
| P1 | 뒤가 앞을 완전히 덮음 | `B_low < A_low AND A_high < B_high` |
| P2 | 위쪽 걸침 (상단 겹침) | `A_low ≤ B_low < A_high AND B_high > A_high` |
| P3 | 위로 분리 (완전 위, 갭 업) | `B_low ≥ A_high` |
| P4 | 아래쪽 걸침 (하단 겹침) | `B_low < A_low AND A_low < B_high ≤ A_high` |
| P5 | 아래로 분리 (완전 아래, 갭 다운) | `B_high ≤ A_low` |

### 3-2. 몸통 상대위치 (PB) → 초성

| 코드 | 의미 | 초성 |
|------|------|------|
| PB0 | 뒤 몸통이 앞 몸통 안에 | **ㅇ** (안에) |
| PB1 | 뒤 몸통이 앞 몸통을 덮음 | **ㄷ** (덮다) |
| PB2 | 위쪽 걸침 | **ㄱ** (위로 걸침) |
| PB3 | 위로 분리 (완전 위) | **ㅅ** (솟다) |
| PB4 | 아래쪽 걸침 | **ㄴ** (아래) |
| PB5 | 아래로 분리 (완전 아래) | **ㅂ** (바닥) |

### 3-3. 레인지 상대위치 (PR) → 종성

| 코드 | 의미 | 종성 |
|------|------|------|
| PR0 | 뒤 범위가 앞 범위 안에 | **ㅇ** (안에) |
| PR1 | 뒤 범위가 앞을 덮음 | **ㄷ** (덮다) |
| PR2 | 위쪽 걸침 (상단 겹침) | **ㄱ** (위로 걸침) |
| PR3 | 위로 분리 (완전 위, 갭 업) | **ㅅ** (솟다) |
| PR4 | 아래쪽 걸침 (하단 겹침) | **ㄴ** (아래) |
| PR5 | 아래로 분리 (완전 아래, 갭 다운) | **ㅂ** (바닥) |

### 3-4. 거래량 상대크기 (Q) → 중성

`vol_rel = (현재 거래량 / 이전봉 거래량) × 100`

| 코드 | 의미 | 조건식 | 중성 |
|------|------|--------|------|
| Q0 | 극감소 | `vol_rel < 40` | **ㅠ** |
| Q1 | 감소 | `40 ≤ vol_rel < 70` | **ㅜ** |
| Q2 | 약간 감소/유지 | `70 ≤ vol_rel < 90` | **ㅓ** |
| Q3 | 거의 비슷(중립) | `90 ≤ vol_rel ≤ 110` | **ㅡ** |
| Q4 | 약간 증가 | `110 < vol_rel ≤ 150` | **ㅏ** |
| Q5 | 증가 | `150 < vol_rel ≤ 250` | **ㅗ** |
| Q6 | 폭발적 증가 | `vol_rel > 250` | **ㅛ** |

### 3-5. 관계 한 글자 예시

두 번째 캔들에 대해:
- 몸통 위치: `PB2` (위쪽 걸침) → 초성: **ㄱ**
- 거래량: `Q4` (약간 증가) → 중성: **ㅏ**
- 레인지 위치: `PR4` (아래쪽 걸침) → 종성: **ㄴ**

→ 관계 글자: **간**

---

## 4. 최종 표현 방식

**5분봉 두 개 = 한글 2글자**

1. **첫 번째 글자:** 현재 캔들 자체 (V-D-S)
2. **두 번째 글자:** 이전 캔들 대비 관계 (PB-Q-PR)

예: `롬간` = "폭발적 강한 양봉 마루보즈" + "몸통 위쪽 걸침, 거래량 약간 증가, 레인지 아래쪽 걸침"

---

## 5. 구현 참고사항

- **변동성 평균 (range_ma):** 최근 60개 5분봉의 range 평균 권장
- **첫 캔들 처리:** 이전 캔들이 없으면 관계 코드는 생략 또는 기본값 처리
- **거래량 0 처리:** 이전 거래량이 0이면 `vol_rel` 계산 불가, 기본 Q3 또는 예외 처리
- **도지 우선순위:** D0 조건을 먼저 확인 후 D1~D6 판정
- **꼬리 우선순위:** S0 → S1 → S2/S3 순서로 판정
